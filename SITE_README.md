# THCD Site

Сайт с прокруткой по фильму, облаком украшений, разделами Sold out и Ring size и оплатой корзины одной кнопкой PayPal (PayPal или банковская карта).

## Что где лежит

- `index.html` — сайт целиком (стили и логика внутри).
- `data/catalog.js` — **цены, товары и архив Sold out**. Здесь же валюта (`EUR`) и доставка (`shipping`, 0 = включена в цену). Сервер берёт цены отсюда, поэтому покупатель не может их подменить.
- `frames/` — 169 кадров фильма для прокрутки (из нового видео site4.mp4).
- `img/soldout/` — сжатые фото 16 проданных колец (полные 1600px и превью 600px).
- `js/ring-size.js` — калькулятор размера кольца со старого сайта.
- `api/` — серверные функции Vercel для PayPal: `config` (публичный Client ID), `orders` (создать заказ), `capture` (списать оплату).

## Как включить оплату

1. Зайди на https://developer.paypal.com → Apps & Credentials.
2. Сначала вкладка **Sandbox** (тест): создай приложение, скопируй Client ID и Secret.
3. В Vercel → проект → Settings → Environment Variables добавь:
   - `PAYPAL_CLIENT_ID` = Client ID
   - `PAYPAL_CLIENT_SECRET` = Secret
   - `PAYPAL_ENV` = `sandbox`
4. Задеплой и проверь оплату тестовым аккаунтом/картой из PayPal Sandbox.
5. Когда всё работает: переключись на вкладку **Live**, создай live-приложение, замени ключи и поставь `PAYPAL_ENV` = `live`.
6. В настройках аккаунта PayPal проверь, что включена оплата картой без аккаунта PayPal (guest checkout), иначе кнопка «Debit or Credit Card» может не показаться.

После оплаты PayPal пришлёт письмо и тебе, и покупателю. В заказе видно каждое изделие и размер кольца (в описании позиции: «Size 17»), адрес доставки покупатель вводит в PayPal.

## Важно

- Открытый двойным кликом `index.html` показывает сайт, но оплата работает только на опубликованном сайте (нужны серверные функции).
- Цены сейчас примерные — поправь их в `data/catalog.js`.
- PayPal не принимает лари (GEL), поэтому цены в евро.
